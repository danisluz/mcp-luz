# TypeScript estrito

- Não use `any`; modele dados externos com tipos, `unknown` e validação.
- Preserve `strict` do projeto e evite asserções de tipo sem validação.
- Altere apenas o escopo solicitado e execute a checagem disponível antes de concluir.
